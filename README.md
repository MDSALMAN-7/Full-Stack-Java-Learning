# Full Stack Java Learning

This repository contains the Java learning project at `Backend/Java`. The project uses
Eclipse's standard `src` source folder and keeps compiled output in `Backend/Java/bin`.
Import `Backend/Java` into Eclipse as an existing project, using a separate workspace
such as `E:/Eclipse-Workspace`.

Java topics are organized into these packages:

- `Day01Basics`
- `Day02InputOutput`
- `Day03Variables`
- `Day04Operator`
- `Day05ConditionalStatement`
- `Day06Loops`
- `Day07Loops`
- `Day08Array`
- `Day09Method`
- `Day10AccessModifier`
- `Day11OOPs`
